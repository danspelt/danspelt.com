## Project Summary

A lightweight, customized maintenance request system for Kenning Property Management. The system will replace the current email-and-spreadsheet workflow with a single web-based tool where residents submit requests, managers assign and track them, and status updates are visible to everyone who needs them.

---

## Scope of Work

### Included

1. Discovery call and written requirements summary.
2. Resident maintenance request form with email notification.
3. Manager dashboard to view, assign, update status, and add notes.
4. Resident-facing status page by request ID.
5. Email notifications at key status changes.
6. Basic reporting dashboard showing open, in-progress, and completed requests.
7. Responsive, accessible interface.
8. Testing and a 14-day user acceptance period.
9. Deployment to a production environment.
10. Handoff documentation and a 30-minute walkthrough.

### Not Included

- Third-party subscription costs (hosting, domain, email service).
- Resident login accounts or full authentication portal.
- Document storage, announcements, or other community features.
- Content migration from existing spreadsheets or email.
- Major scope changes after the build begins.
