# Business Documents

This folder contains reusable templates and one filled-out example for going to market with custom software services.

## Reusable Templates

- `outreach-targets.md` — industries to target and why property management is the best first choice
- `outreach-email.md` — cold email template for small property management firms
- `quote-template.md` — customizable project quote
- `engagement-letter.md` — service agreement / contract template
- `satisfaction-guarantee.md` — guarantee and continuity promise template
- `invoice-process.md` — payment methods, terms, and internal pricing guidelines

## Mock Client Example

The `mock-client/` folder contains filled-out versions of the quote, engagement letter, guarantee, and invoice for a fictional property management firm. Use this as the script for the dress rehearsal before going live.

## Next Steps

1. Review all templates and adjust pricing, terms, and branding as needed.
2. Use the outreach email template to send the first real (or mock) email.
3. Run through the mock-client rehearsal with a friend or mentor.
4. When ready, replace placeholder contact details with real ones.
